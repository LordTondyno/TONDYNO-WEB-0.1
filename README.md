# TONDYNO PROJECT

Standalone analog photography project archive by Tony Dang.

## Structure
- `index.html` — projects overview
- `project.html` — project detail template
- `css/style.css` — global styles
- `js/projects.js` — project content and image paths
- `js/main.js` — project grid, category filters and search
- `js/project-detail.js` — project detail rendering
- `assets/images/` — your photographs

## Preview
Open `index.html` in a browser. For development, a local server such as the VS Code Live Server extension is recommended.

## Adding photographs
1. Copy your photographs into `assets/images/`.
2. Open `js/projects.js`.
3. Replace `cover` with the cover image path.
4. Replace the entries in `images` with the paths of the photographs for that project.
5. Edit title, category, year, camera, film and descriptions.

This is an initial scaffold. Replace the sample projects and placeholder images with your own work before publishing.
